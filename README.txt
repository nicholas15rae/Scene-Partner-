Optional extra Studio voices.

By default Studio uses Chatterbox's built-in voice. Chatterbox can also copy the sound of a
short reference recording (5-15 seconds, .wav). If you put one here it appears as a Studio voice.

ONLY use recordings you have the rights to: your own voice, or a voice whose owner has given you
explicit permission. Never use recordings of real people (actors, celebrities, friends) without
their consent. Name the file m_name.wav or f_name.wav to list it under Male or Female.

Nothing in this folder ever leaves your computer.
